# Limbus Company — „Plik META” — spis serii

Czwarta seria Czytanek: elementy spoza trzech głównych grup (fabuła / plik ID / plik E.G.O) — teksty tutoriali z misji, Notatki Dantego, splashe pobierania patcha, akta Grzeszników i piosenki. Deploymenty misji (przeciwnicy ze statystykami) mają osobną serię `deployment_<LANG>` — tabela na końcu tego pliku.

Poza zakresem serii (osobne grupy albo teksty interfejsu bez treści fabularnej): `TutorialMainUIText` (przechadzki po interfejsie), `TutorialMirrorDungeon` (tutorial Lustrzanych Lochów), starsze zestawy `TutorialDesc*` (poprzednia wersja tutoriali).
